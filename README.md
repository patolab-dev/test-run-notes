# テスト実施ノート (Test Run Notes)

Markdownで書いたテストチェックリストを読み込み、日付・実施者・結果(OK/NG/スキップ)・備考を記録して、結果入りのMarkdownとしてエクスポートできる、ローカルで動く軽量なテスト実施記録ツールです。

サーバーやビルド、インストールは一切不要です。`checklist.html` をブラウザで開くだけで使えます。

## 特長

- 単一HTMLファイルで完結（サーバー不要、ネット接続不要、ダブルクリックで起動）
- Markdownのチェックリストを読み込んで、日付・実施者・結果(未実施/OK/NG/スキップ)・備考を項目ごとに記録
- 全体件数・未実施件数・実施済み件数・OK件数・NG件数・スキップ件数をリアルタイム表示
- 入力内容はブラウザに自動保存され、閉じても同じファイルを読み込み直せば続きから再開可能
- 結果入りのMarkdownをエクスポートでき、そのファイルを再度読み込めば編集を継続できる

## 使い方

1. `checklist.html` をブラウザ（Chrome推奨）で開く
2. 「mdファイルを選択」から、下記フォーマットのチェックリストMarkdownを読み込む
3. 各項目について、未実施/OK/NG/スキップを選択（OK・NG・スキップを選ぶと日付が自動入力されます）
4. 上部の「実施者名」「実施日」欄に入力し、「全項目に適用」で未入力の項目にまとめて反映できます
5. 「結果をエクスポート」で、結果を反映したMarkdownをダウンロード
6. 中断した場合は、同じファイルを再度読み込むと続きから再開するか確認されます。エクスポート済みのファイルを読み込んだ場合は、その内容がそのまま復元されます

サンプルとして `sample_checklist.md` を同梱しています。まずはこれを読み込んで動作を確認してみてください。

## 入力Markdownのフォーマット

`##` で機能ごとにセクションを分け、各セクションの直下に「項目」列のみを持つMarkdownテーブルを書きます。

```markdown
## ログイン機能

| 項目 |
| --- |
| 正しいID/パスワードでログインできる |
| 誤ったパスワードでエラーメッセージが表示される |

## 検索機能

| 項目 |
| --- |
| キーワードを入力して検索結果が表示される |
```

## 出力Markdownのフォーマット

エクスポートすると、元のテーブルに「日付・実施者・結果・備考」列が追加された形式で出力されます。このファイルを再度読み込めば、続きから編集できます。

```markdown
## ログイン機能

| 項目 | 日付 | 実施者 | 結果 | 備考 |
| --- | --- | --- | --- | --- |
| 正しいID/パスワードでログインできる | 2026-09-11 | 三木 | OK |  |
| 誤ったパスワードでエラーメッセージが表示される | 2026-09-11 | 三木 | NG | エラー文言が出ない |
```

## テストケースを生成するプロンプト

仕様書や機能一覧をお持ちの場合、以下のプロンプトをLLM（Claudeなど）に投げると、このツールに対応したチェックリストMarkdownを生成できます。

```
以下の仕様書・要件定義をもとに、テストチェックリストをMarkdownで作成してください。

出力ルール:
- 機能・画面ごとに「## 見出し」でセクションを分けてください
- 各セクションの直下に、1列のMarkdownテーブルを作成してください。ヘッダーは「| 項目 |」としてください
- 各行には、結果が明確にわかる具体的で検証可能なテスト項目を1つずつ書いてください(例:「〜できる」「〜が表示される」「〜はエラーになる」)
- 正常系だけでなく、異常系・境界値のケースも含めてください
- 結果・日付・実施者などの列は含めないでください(ツール側で自動的に追加されます)

出力フォーマット例:
## ログイン機能
| 項目 |
| --- |
| 正しいID/パスワードでログインできる |
| 誤ったパスワードでエラーメッセージが表示される |

対象の仕様書:
（ここに仕様書・要件定義・機能一覧などを貼り付け）
```

## 動作環境

- モダンブラウザ（Chrome, Edge, Safari など）
- 自動保存にはブラウザのlocalStorageを使用します。ブラウザのプライベートモードや設定によっては保存されない場合があります
